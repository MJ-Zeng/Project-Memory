## 3. 未验证 / 需复核关注

1. **AC-11 独立复核**：未做，判定权在 PM-03；负例“默认执行即 FAIL”由复核方执行。
2. **Linux 原生 / 无 WSL 的 CI**：本机只验证 Windows + WSL2 Ubuntu；无 WSL 环境应表现为 `--trusted` → exit 3（已用 `DISABLE_WSL=1` 模拟），未在真实无 WSL 主机跑。
3. **trusted 日志 WSL NAT 横幅乱码**：`clean_stderr` 未过滤该 UTF-16 乱码形态；隔离结论不受影响，属既有显示瑕疵，未修。
4. **显式 local 的滥用**：Agent 习惯性加 `--allow-local-untrusted` 会让默认拒绝形同虚设；属流程/审查问题（ADR §7.4），复核时建议检查是否滥用。
5. **历史脚本**：`pilot/kit/b1/*`、`pilot/evidence/B0/*`、`evidence/B5A/*` 探针仍是旧调用；它们是冻结历史产物，未重跑、未修改（ADR §6）。
6. **库默认未改**：`run_command(mode='local')` 仍默认 local（内部/测试原语）。这是刻意选择，安全边界在 CLI；若复核认为库默认也必须收紧，需另立范围并同步全部调用方。

## 4. 复现要点

- 解释器：PATH 上 `python` 是 WindowsApps 存根（exit 49），须用 `C:/SoftWare/Anconda/python.exe`。
- 复现默认拒绝：`<py> -m project_memory test-run --repo . --command "<cmd>"` → exit 3。
- 显式 local：追加 `--allow-local-untrusted`。
- trusted：追加 `--trusted`（需 WSL2；不可用时 `PROJECT_MEMORY_DISABLE_WSL=1` 模拟 exit 3）。
- 具体命令/退出码见 `commands.jsonl`；哈希见 `sha256sums.txt`。
