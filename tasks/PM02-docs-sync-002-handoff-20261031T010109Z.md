## 4. 文本检查（可重复命令）

脚本写入 `C:/Temp/pm02_textcheck.sh`，在仓库根目录执行 `bash C:/Temp/pm02_textcheck.sh`。规则：非历史文件里不得出现无保留的过时断言；`docs/TEST_REPORT.md` 里的历史句必须在其后 1–2 行内带有 `2026-10-31 更新（B-9 之后）` 注记，否则失败。脚本内容逐字如下：

```bash
#!/usr/bin/env bash
STALE='只接受.*agent_claimed|CLI 离线|不抓取 CI|不联网抓取|没有抓取或认证真实状态'
FILES='skill/project-memory/SKILL.md skill/project-memory/references/data-contracts.md skill/project-memory/references/workflows.md skill/project-memory/references/governance.md pilot/PILOT_R1_CHARTER.md docs/ARCHITECTURE.zh-CN.md docs/OPERATIONS.zh-CN.md'

echo '== non-historical files: expect no stale match =='
if grep -nE "$STALE" $FILES; then
  echo 'TEXT-CHECK=FAIL (stale in non-historical file)'; exit 1
fi

echo '== TEST_REPORT: stale lines must be followed within 2 lines by dated note =='
awk -v pat="$STALE" '{ line[NR]=$0 } END {
  bad=0
  for (i=1;i<=NR;i++) {
    if (line[i] ~ pat) {
      found=0
      for (j=i+1;j<=i+2 && j<=NR;j++)
        if (line[j] ~ /2026-10-31 更新（B-9 之后）/) found=1
      if (!found) { print "TEST_REPORT stale without dated note at line " i; bad=1 }
    }
  }
  if (bad) { exit 1 }
}' docs/TEST_REPORT.md || { echo 'TEXT-CHECK=FAIL (TEST_REPORT stale without note)'; exit 1; }

echo 'TEXT-CHECK=OK'
exit 0
```
