# approvals — 审批事件存放分支

本分支只存放签名审批事件（`approval_event` JSON），供 CI 的 `approval-gate` 读取。
它不是代码分支，不参与 `dev/v1.0` 的合并。

## 规则

- 每条记录一个文件：`records/<commit_sha>-<approval_id>.json`，`commit_sha` 为被审批的完整 40 位提交。
- 记录必须由仓库外的受保护私钥签名；本分支不得存放私钥、凭据或任何私密材料。
- 记录格式与摘要算法见代码仓库 `skill/project-memory/references/data-contracts.md` 的“审批记录”一节。
- 门禁只读取本分支的 `records/`，并按 PR head 提交过滤；本分支不满足任何检查时门禁失败。
- 审批私钥的托管与签名主体责任不属于本分支；本分支的提交历史本身就是审批发布记录。

## 注意

- 本分支不受分支保护约束，也**不能**代替分支保护：仓库管理员仍可改写本分支。
- 本分支公开存放的是审批事件的签名与公钥可验证内容，不含任何密钥材料。
